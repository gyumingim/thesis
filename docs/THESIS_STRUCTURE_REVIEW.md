# 학위논문 구조 진단 (2026-08-27, 조사 에이전트 — 출처 검증 포함)

## 진단 요약

### 빠진 것 (심사 통과에 결정적)

1. **독립된 '결론' 장이 없음 — 가장 큰 결함.** 국내 대학원 규정은 자연계·공학 논문 본문을 "서론 → 재료 및 실험방법 → 결과 및 고찰 → **결론** → 참고문헌 → 초록"으로 명시하며(충남대 규정 원문 확인), 국내 논문작성법 교재도 마지막 장을 "요약 및 결론"으로 요구. CS 관례(Keselj, Dalhousie)도 결론 장에 **기여 요약 + Future Work** 필수. 현재 7장이 논의·한계·향후를 겸하는 구조는 "결론 없이 끝나는 논문"으로 형식 심사에서 바로 지적됨.
2. **국문초록·영문초록이 목차에 없음.** 대부분 대학이 두 언어 초록 요구(키워드 규정 존재), 국문 논문이면 영문초록을 말미(참고문헌 뒤)에 배치하는 식으로 위치까지 규정. 감사의 글, 표·그림 목차도 전면부 필수 — 소속 대학원 규정 확인 필요.
3. **서론에 '논문 구성(로드맵)' 절 없음.** 두 트랙 논문에서는 각 장이 전체 논지에 어떻게 귀속되는지 서론에서 선언하는 것이 "스테이플 비판"의 1차 방어선.
4. **연구 질문 회수 구조 없음.** 1.2에서 던진 질문을 결론에서 질문별로 명시 회수해야 함 — 심사위원이 체크리스트처럼 확인하는 항목.

### 과잉·오배치

1. **"부록 B 참고문헌" — 명백한 형식 오류.** 참고문헌은 부록이 아니라 독립 필수 요소. 표준 순서: 본문 → **참고문헌** → 부록 (→ 규정에 따라 초록). 부록 라벨은 형식 심사 반려 사유.
2. **7장의 "처방 3종 검증"** — 검증 실험은 결과이므로 6장으로 이동(6.5)이 정석.
3. **4장 제목의 "방법론"** — 내용(여섯 라운드 반복 실험 서사)은 사실상 경험적 발견.

### 순서·구조 문제

**3·4·5장 분리는 정당화 가능** — contribution-per-chapter 는 허용되나 "예외는 잘 정당화되어야 한다". 4장은 **반복적 정합 연구라는 중간 결과**, 5장은 그로부터 귀납된 개념 기여이므로 순서는 옳음. 해법은 재배치가 아니라 **역할 선언**: 4장 제목에서 "방법론" 제거("정합 과정: 여섯 라운드의 실패 지문"), 각 라운드를 가설→개입→관측 구조로, 장 서두에 "이 장은 절차이자 발견" 명시. 5장 서두는 "4장의 실패 지문들로부터 도출한 원리"로 개시.

**6.4 승격 여부**: percept 4-arm이 지지집합 원리의 교차 도메인 검증이라면 **6.4 유지**가 맞고, 제목을 "지지집합 원리의 교차 검증: 인지 파이프라인"으로 바꿔 종속성 명시가 두-트랙 비판의 최선 방어. 별도 장 승격은 "두 논문" 인상을 강화하므로 비추천. 통합 서사 전략: (1) 단일 명제 스파인 — "시뮬 간 전이 붕괴의 원인은 관측 지지집합 불일치" 우산 아래 RL 비교=현상 확립, 인지 파이프라인=원리의 일반화 검증으로 종속 배치, (2) 각 장 끝 브리지 단락, (3) 결론에서 두 트랙 재봉합. "에세이 스테이플" 비판과의 차이는 연결 단락이 만든다.

**부록 A 재현성 — 강점, 보강**: NeurIPS 체크리스트 형식(질문—Yes/No/NA—정당화), 코드·데이터 가용성 진술, Henderson 권고(시드 수·시드별 결과·하이퍼파라미터 전수·환경 버전·통계 검정 방식). 5시드 논문이므로 시드별 분산·검정 방식 명시는 가점 요소.

## 권장 목차 개정안 (현 구조 최소 수정)

- 전면부: 국문초록(규정 위치 확정) · 목차 · 표/그림 목차
- **1. 서론** — 1.1 배경, 1.2 연구 질문, 1.3 기여, **1.4 논문 구성(신설)**
- **2. 관련 연구** (유지)
- **3. 방법** (유지)
- **4. 정합 과정: 여섯 라운드의 실패 지문** (제목 수정 + 역할 선언 단락)
- **5. 관측 지지집합 원리** (유지, "4장으로부터의 귀납" 개시)
- **6. 결과** — 6.1~6.3 유지, **6.4 제목 변경**("지지집합 원리의 교차 검증: 인지 파이프라인·percept 4-arm"), **6.5 처방 3종 검증(7장에서 이동)**
- **7. 논의 및 한계** (향후 연구 제거)
- **8. 결론 및 향후 연구(신설)** — 연구 질문별 답 회수, 기여 요약, 향후 연구
- **참고문헌** (부록 라벨 제거, 독립 요소)
- **부록 A. 재현성** — 함정 서술 + 체크리스트 표 + 코드 가용성 진술 + 시드/통계 보고
- 말미: 영문초록 — 대학원 규정 위치 확인

최소 수정 요지: 장 신설은 8장 하나, 나머지는 제목 변경·절 이동·라벨 수정.
